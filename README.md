## 🔄 &nbsp;How My Apps Are Wired

```mermaid
flowchart LR
    U([👆 User]) --> V[🎨 View<br/>SwiftUI / UIKit]
    V -- "user intent" --> VM[🧠 ViewModel<br/>@Published state]
    VM --> S[🌐 Service Layer<br/>URLSession · async/await]
    S --> API([☁️ REST API])
    API -- "JSON" --> D[📦 Codable Models]
    D --> VM
    VM -- "state: loading / success / error" --> V
    VM --> P[(💾 Persistence<br/>Core Data · Keychain)]
    P --> VM

    style U fill:#FF9F0A,stroke:#fff,color:#000
    style V fill:#0A84FF,stroke:#fff,color:#fff
    style VM fill:#BF5AF2,stroke:#fff,color:#fff
    style S fill:#5E5CE6,stroke:#fff,color:#fff
    style API fill:#8E8E93,stroke:#fff,color:#fff
    style D fill:#30D158,stroke:#fff,color:#000
    style P fill:#FF375F,stroke:#fff,color:#fff
```

> No massive view controllers. No business logic in the UI layer. Every screen testable on its own.

<br>

- **Clean code isn't decoration.** The next developer might be me in six months, tired.
- **Architecture before features.** Bolting MVVM on afterwards costs three times more.
- **Pixel-perfect is a requirement, not a bonus.** Users don't say "misaligned" — they say "cheap".
- **Every state is a real state.** Loading, empty, error, offline. Not just the happy path.
- **Reuse over repeat.** If I write it twice, it becomes a component.
